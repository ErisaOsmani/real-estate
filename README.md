# 🏠 Real Estate AI App

## 📌 Description
This project is a Real Estate AI application that helps users generate professional property descriptions, save them, and manage their listings.

The system is built with Next.js, Supabase, and an AI API for generating descriptions.

---

## ✨ Features
- AI-generated property descriptions
- Save properties to database
- Duplicate save protection
- Input validation (empty & max length)
- Loading states during generation
- Error handling (network & API errors)
- Success messages for better UX
- Empty state handling

---

## 🛠 Tech Stack
- Next.js
- React
- Supabase (Auth + Database)
- OpenAI API (or backend AI route)
- Tailwind CSS
